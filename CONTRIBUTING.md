# Sharing and contributions

Skyloom is a personal project by Nick Richards, shared so that others can use it,
learn from it and make it their own. Forks and adaptations are warmly welcome
under [GPLv3 or later](LICENSE.md).

Thoughtful bug reports and contributions are welcome too. Development follows
the maintainer's interests and available time, so review, support and inclusion
of changes cannot be guaranteed. For a substantial change, discussing the idea
first can help establish whether it fits the project's direction. A fork is
always a welcome home for a different approach.

For contributions, start with the [development guide](docs/DEVELOPMENT.md) and
[roadmap](docs/ROADMAP.md). Keep
changes focused, follow the existing native GNOME design, and describe the
behaviour changed and the checks performed. Run `./scripts/check.sh` and the
checks appropriate to your change; run native tests and GUI smokes sequentially.
Contributed original work is supplied under the project's GPLv3-or-later licence.

Use only invented accounts and posts in tests and screenshots. Never include
passwords, session tokens, keyring contents, account databases, private posts or
unredacted diagnostic logs in an issue or contribution. Use a dedicated app
password entered directly into the app for your own account testing; never share
it with the maintainer or an automated agent.
